Files:
- index.html: Home page
- services.html: Services page
- industries.html: Industries page
- about.html: About Us page
- portfolio.html: Portfolio page
- contact.html: Contact page
- assets/css/style.css: Responsive blue theme and shared styles
- assets/js/components.js: Shared navbar/footer insertion
- assets/js/main.js: Mobile menu and FAQ interactions

HOW TO RUN:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Right-click index.html and select Open with Live Server.
4. Use the navbar to check Services, Industries, About Us, Portfolio and Contact pages.
